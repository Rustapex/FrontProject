# 캐치테이블 스타일 식당 예약 프론트엔드 프로젝트

HTML, CSS, JavaScript를 사용해 제작한 식당 탐색 및 예약 UI 프로젝트입니다.
캐치테이블과 흑백요리사 콘셉트를 참고하여 식당 목록, 카테고리 필터, 상세 화면, 날짜·인원·시간 선택, 예약 현황 확인 기능을 정적 웹 페이지로 구현했습니다.

> 본 프로젝트는 프론트엔드 화면 구현 중심의 학습 프로젝트입니다.
> 실제 서버와 DB는 연결되어 있지 않으며, 예약 데이터는 브라우저의 `localStorage`를 사용해 저장됩니다.

---

## 1. 프로젝트 소개

이 프로젝트는 모바일 앱 형태의 식당 예약 서비스를 웹 화면으로 구현한 프론트엔드 프로젝트입니다.
사용자는 식당 목록을 확인하고, 백수저/흑수저 카테고리와 필터 UI를 통해 식당을 탐색할 수 있습니다.
또한 날짜, 인원, 시간을 선택해 예약을 진행하고, 예약 현황 페이지에서 저장된 예약 내역을 확인할 수 있습니다.

---

## 2. 주요 기능

### 식당 목록 화면

* 식당 카드 목록 표시
* 식당명, 평점, 리뷰 수, 지역, 음식 종류, 가격 정보 표시
* 백수저 / 흑수저 탭 필터
* 지역, 음식 종류, 가격 조건 필터 UI
* 모바일 앱 형태의 480px 중심 레이아웃

### 예약 기능

* 식당별 예약 화면 이동
* 날짜 선택
* 인원 선택
* 시간 선택
* 예약 가능 / 불가능 시간 표시
* 예약 완료 데이터 저장

### 예약 현황 기능

* 저장된 예약 내역 조회
* 예약 취소 기능
* 예약 취소 시 저장된 예약 슬롯 해제

### 화면 구성

* 시작 화면
* 인트로 화면
* 식당 목록 화면
* 식당 상세 화면
* 예약하기 화면
* 예약 현황 화면

## 5. 실행 방법

별도의 서버 설치 없이 브라우저에서 실행할 수 있습니다.

```bash
git clone https://github.com/Rustapex/FrontProject.git
cd FrontProject
```

그 후 `index.html` 파일을 브라우저에서 열면 됩니다.

또는 VS Code의 Live Server 확장 프로그램을 사용해 실행할 수 있습니다.

```text
index.html 우클릭 → Open with Live Server
```

## 6. 구현 포인트

### 1. 정적 페이지 기반의 예약 흐름 구현

서버 없이 HTML, CSS, JavaScript만으로 식당 탐색부터 예약 현황 확인까지의 흐름을 구현했습니다.

### 2. Web Storage 활용

예약 데이터와 예약된 시간 슬롯 정보를 `localStorage` 또는 `sessionStorage`에 저장하여 페이지 이동 후에도 예약 상태가 유지되도록 구현했습니다.

### 3. 모바일 중심 UI

모바일 앱처럼 보이도록 480px 고정 폭 레이아웃, sticky header, bottom sheet 형태의 UI를 적용했습니다.

### 4. 동적 렌더링

JavaScript 더미 데이터를 기반으로 식당 카드, 날짜 버튼, 시간 버튼 등을 동적으로 렌더링했습니다.

## 7. 한계 및 개선 예정 사항

* 현재는 실제 서버와 DB가 연결되어 있지 않습니다.
* 예약 데이터는 브라우저 저장소에만 저장됩니다.
* 새 기기나 다른 브라우저에서는 예약 내역이 공유되지 않습니다.
* 실제 서비스 수준의 회원 인증, 결제, 예약 중복 검증은 포함되어 있지 않습니다.

향후 개선한다면 다음 기능을 추가할 수 있습니다.

* 백엔드 API 연동
* DB 기반 예약 저장
* 회원 로그인 기능
* 실제 예약 중복 검증
* 관리자 예약 관리 기능
* 이미지 및 데이터 출처 정리
* 반응형 UI 개선
